# Заметки о работе с Git в VS Code

## Что удобно в VS Code:
1. Визуальный diff — сразу видно, что изменилось.
2. Быстрый коммит через интерфейс (не нужно запоминать команды).
3. GitLens показывает историю строк прямо в редакторе.

## Что удобнее в терминале:
1. Работа с ветками (git branch, git checkout) — быстрее через команды.
